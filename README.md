# Umut Birthday World — Interactive Edition

Bu sürüm önceki sade tasarımın yerine daha hareketli, tatlı ve interaktif bir doğum günü sitesi olarak hazırlanmıştır.

## İçerik
- Hareketli açılış
- Uçuşan kalpler ve parıltılar
- Scrapbook / polaroid fotoğraf alanı
- Yatay kaydırmalı hikâye
- Açılan mektuplar
- Sürpriz kutuları
- Şifreli kutu
- Quiz + skor + konfeti
- Gelecek dilekleri
- Final sürprizi

## Fotoğraflar
`assets/photo-1.jpg` ile `photo-10.jpg` dosyalarını kendi fotoğraflarınla aynı isimlerde değiştir.

## Yazılar
`index.html` içindeki metinleri değiştirebilirsin.

## Quiz
`script.js` içindeki `qs` dizisinden soru, seçenek ve doğru cevapları değiştir.

## Müzik
Şimdilik buton yer tutucudur. İstersen sonraki adımda kendi şarkını siteye ekleyip oynat/durdur özelliği yapabiliriz.

## Çalıştırma
`index.html` dosyasını tarayıcıda açabilir veya VS Code'da Live Server kullanabilirsin.
